Windows

Paste this into PowerShell as administrator. The certificate is part of the command; the box shows only its start. It installs only if the check code fits:

$cert = [Security.Cryptography.X509Certificates.X509Certificate2]::new([Convert]::FromBase64String("{{ cert.der_base64 }}"))
$code = -join ([Security.Cryptography.SHA256]::Create().ComputeHash($cert.RawData)[0..5] | ForEach-Object { $_.ToString("X2") })
if (((Read-Host "Check code") -replace "[^0-9A-Fa-f]") -eq $code) { $store = [Security.Cryptography.X509Certificates.X509Store]::new("Root", "LocalMachine"); $store.Open("ReadWrite"); $store.Add($cert); $store.Close(); "Installed: " + $cert.Subject } else { "Wrong check code, nothing was installed." }

Or with the downloaded file from your download folder:

Import-Certificate -FilePath "$env:USERPROFILE\Downloads\{{ file_name }}" -CertStoreLocation Cert:\LocalMachine\Root

Do not use the import wizard with "automatically select the certificate store": Windows then does not trust the CA and says nothing.

{% endif %} {% if shown == "macos" %}

macOS

Print the check code of the downloaded file first and compare it:

openssl x509 -in ~/Downloads/{{ file_name }} -noout -fingerprint -sha256 | cut -d= -f2 | tr -d : | cut -c1-12
sudo security add-trusted-cert -d -r trustRoot -k /Library/Keychains/System.keychain ~/Downloads/{{ file_name }}

Or by hand: add the file to the keychain System, then set "When using this certificate" to "Always Trust" in Keychain Access.

{% endif %} {% if shown == "linux" %}

Debian and Ubuntu

Print the check code of the downloaded file first and compare it:

openssl x509 -in {{ file_name }} -noout -fingerprint -sha256 | cut -d= -f2 | tr -d : | cut -c1-12
sudo cp {{ file_name }} /usr/local/share/ca-certificates/{{ file_name }}
sudo update-ca-certificates

The file name has to end in .crt.

{% endif %} {% if shown == "ios" %}

iPhone and iPad

  1. Tap the download button above in Safari and allow the configuration profile.
  2. Settings, General, VPN & Device Management: open the profile. Under "More Details", the first 12 characters of the SHA-256 fingerprint are the check code. Then tap Install.
  3. Settings, General, About, Certificate Trust Settings: switch the certificate on.
{% endif %} {% if shown == "android" %}

Android

  1. Download the file with the button above.
  2. Settings, Security & privacy, More security settings, Encryption & credentials, Install a certificate, CA certificate. Or search the settings for "CA certificate".
  3. Under "Trusted credentials", tab "User": the first 12 characters of the SHA-256 fingerprint are the check code. Remove it if they differ.

Chrome trusts it. Many other apps ignore certificates the user installed.

{% endif %} {% if shown == "chrome" %}

Chrome and Edge

On Windows, macOS and Android these browsers use the system store: follow the steps for the system, then restart the browser.

On Linux they keep their own list. Print the check code of the downloaded file first and compare it:

openssl x509 -in {{ file_name }} -noout -fingerprint -sha256 | cut -d= -f2 | tr -d : | cut -c1-12
certutil -d sql:$HOME/.pki/nssdb -A -t "C,," -n "{{ file_name }}" -i {{ file_name }}

certutil comes with libnss3-tools on Debian and Ubuntu. Or import the file at chrome://certificate-manager.

{% endif %} {% if shown == "firefox" %}

Firefox

Firefox keeps its own list. Import it under Settings, Privacy & Security, Certificates, View Certificates, Authorities, and tick "Trust this CA to identify websites". Or set this to true in about:config:

security.enterprise_roots.enabled

Firefox on Android: install the certificate as under Android, then open Settings, About Firefox, tap the logo five times and switch on "Use third party CA certificates".

Back up the CA itself

If the root key is lost, a new root has to be imported on every device. Caddyman cannot back it up: it lives {% if internal %}in Caddy's data volume{% else %}in the volume of your CA{% endif %}. Adjust the volume name:

{% if internal %} 
docker run --rm -v caddy_caddy_data:/data -v "$PWD":/backup alpine \
  tar czf /backup/caddy-pki-backup.tar.gz -C /data/caddy pki
{% else %} 
docker run --rm -v stepca_stepca_data:/data -v "$PWD":/backup alpine \
  tar czf /backup/ca-backup.tar.gz -C /data .
{% endif %}

The archive contains the private key of the CA. Store it accordingly.
